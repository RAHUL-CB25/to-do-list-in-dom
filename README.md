
# To-Do List
A simple To-Do List web application built using HTML, Tailwind CSS, and JavaScript.

## Features
- Add tasks
- Add tasks using Enter key
- Mark tasks as completed
- Delete tasks 
- Drag and drop tasks to reorder them

## Technologies
- HTML
- Tailwind CSS
- JavaScript
- Vite

## File Structure

```text
to-do/
│
├── node_modules/
├── .gitignore
├── index.html
├── index.css
├── index.js
├── package.json
├── package-lock.json
├── README.md
└── vite.config.js
````

## Run Project

```bash
npm install
npm run dev
```
